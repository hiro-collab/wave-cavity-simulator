# 無波から、共振が生まれるまで

## この動画で見ているもの

初期変位と初期速度がともにゼロの、2D質点・バネ格子です。
キャビティ内部の12か所に短い広帯域の加振パルスを与え、波が広がり、
質量・バネ定数の境界で反射・透過し、戻った波どうしが重なる過程を計算しました。
最初から定在波を置いたり、定在波の式を時間表示したりはしていません。

前の計算の層構成を保持しています。

- 通常部とキャビティ：質量 m=1、バネ定数 K=1。
- 縦の色枠の材料：m=4、K=2。
- 左は3組、右は2組の層構造。通常層20格子、高インピーダンス層14格子。
- キャビティは x=522…761、幅240格子。
- 反射率や透過率は入力しません。すべて隣接点のバネ力から決まります。

## 見方

- 上：計算した変位 u(x,y,t) の2D分布。
- 白い破線：y=200。
- 左下：その破線上の u(x,200,t)。上と別に作った図ではありません。
- 右下：表示キャビティ内のエネルギー。同じ12個の力を加えた「多層なし」も計算しています。
- 色と断面の目盛は、弱い残響も見えるよう固定の asinh 目盛を使っています。
  毎フレームの振幅を最大値1にする処理や、途中から振幅を増幅する処理はありません。
- 初めの8 T0までは1 T0を2秒、その後は1 T0を0.5秒で再生します。
  T0=80はパルスの中心周波数の基準周期で、厳密な単色波の周期ではありません。

## なぜ共振に近い状態が残るのか

各点から出た波は、材料境界に来ると一部が透過し一部が戻ります。
戻った波と、別の点から来た波が重なり、場所ごとに強め合い・弱め合いが生じます。
何度も往復する間、往復時の位相が合い、外へ逃げにくい成分は長く残ります。
早く逃げる成分が減るので、残響では共振器に適した形が相対的に目立ちます。

これは「全ての波が後から同じ周波数・位相になる」計算ではありません。
線形の受動系なので、初めに励起された複数の成分が、それぞれの損失で減衰します。
この構成では複数の共振ピークが残り、互いのうなりもあります。
単一モードへの選択・位相同期・レーザー発振は実証していません。

レーザーでは、この受動的な共振条件に加え、利得、飽和、モード間の競合などが必要です。
本計算には利得媒質・誘導放出・飽和はありません。波源を止めた後は、残った波も最終的には減衰します。

## 波源の指定

12点の位置、開始時刻、振幅の符号を乱数種 420731 で固定しています。
同位相の単色正弦波を12点に加えたものではありません。

各時間波形は、ガウス関数の2階微分に比例するパルスです。

    z = (t − t_center) / sigma
    f(t) = A (1 − z²) exp(−z² / 2),  |z| ≤ 4
    f(t) = 0,                       |z| > 4

sigma=18=0.225 T0。無限長の理想波形のスペクトル最大はおよそ f0=1/T0です。
振幅 A は正負が異なり、各点の中心時刻も異なります。
空間的には標準偏差1.5格子の小さなガウス分布で、9×9点に力を分配します。
すべての加振は t=4.55034 T0 までに終了し、以後は力を一切加えません。
パルスの位置・時刻・振幅の全値は config.json に保存しています。

## 運動方程式

格子間隔を1としたスカラー変位です。上の色は光の軌跡ではなく、変位の符号と大きさです。

    m(x) ü(x,y) = Kx(x)[u(x+1,y) − u(x,y)]
                 − Kx(x−1)[u(x,y) − u(x−1,y)]
                 + K(x)[u(x,y+1) + u(x,y−1) − 2u(x,y)]
                 − m(x) gamma(x,y) u̇(x,y) + F(x,y,t)

材料境界をまたぐ x方向のバネ Kx は、隣接する材料の K の調和平均です。
格子数1250×401、時間刻み0.3、計算時間4800=60 T0。
外周は固定ですが、その内側に緩やかな減衰領域を設け、戻り波を抑えています。
表示域内とキャビティ内部に、共振させるための人工的な減衰やモード投影はありません。
上下には吸収領域があり、斜めの波は横方向にも逃げます。
曲面鏡のような横方向の閉じ込めは実装していません。

## 対照実験

「多層なし」は全域 m=1、K=1 とし、加振点・時刻・加振力・吸収領域は同じです。
ただし、同じ加振力でも運動が違えば加振の仕事量は異なります。
実際の総仕事は、多層あり6.4900、なし6.6866です。
そこで動画のエネルギー比較は、各計算の波源停止時をそれぞれ1として表示しています。
比較するキャビティ領域は x=522…761、y=100…300です。

波源停止時に対する内部エネルギーの残り方：

| 時刻 | 多層あり | 多層なし |
|---|---:|---:|
| 8 T0 | 11.83% | 0.2787% |
| 15 T0 | 7.026% | 0.001333% |
| 30 T0 | 2.810% | 0.0000390% |
| 60 T0 | 0.7150% | 0.00000188% |

## 検証

- 初期の表示変位は全点で厳密にゼロ。
- 2Dの中央行と断面データの差は全フレーム・共通点で厳密にゼロ。
- 時間刻みを0.3から0.15へ半分にした独立計算と比較。
  最初の20 T0の全保存フレームの相対RMS差は約0.0414%、20 T0時点は約0.124%。
- 入力仕事、蓄積エネルギー、吸収による散逸の離散的な収支誤差：
  多層あり約3.7×10⁻¹⁴、多層なし約3.5×10⁻¹⁴（総入力仕事比）。
- この収支は、中央差分積分法に対応する交差時刻の離散エネルギーで検証しています。
  連続時間の誤差がゼロ、または格子解像度が無限であるという意味ではありません。
- 波源停止後 8…60 T0 の内部変位スペクトルには、f/f0 ≈
  0.711、0.865、0.999、1.153、1.307 の複数ピークがあります。
  空間・時間分解能および窓関数に依存する値で、固有周波数の厳密値ではありません。
- スペクトルは y方向平均を取り、各内部x点の時間PSDを平均したものです。
  この平均やスペクトル処理は分析専用で、時間発展には使っていません。

validation_plots.png にはエネルギー比較と、広帯域の入力／ピークを持つ残響のスペクトルを示します。
スペクトル2曲線は各々の最大値で規格化しており、両者の高さを利得として読むことはできません。

## 再現

必要なもの：C++17対応コンパイラ、Python、NumPy、SciPy、Matplotlib、Pillow、FFmpeg。
日本語フォント Noto Sans CJK のパスは render.py 内で指定しています。
全実行には数百MBの一時データが生成されます。動画と添付ZIPでは巨大な生データを重複させていません。

    python configure.py
    g++ -O3 -std=c++17 simulate.cpp -o simulate
    ./simulate
    python analyze.py
    python render.py

または、同じフォルダで `bash run.sh` を実行してください。
時間刻みを半分にする独立検証は、通常計算の後で `bash verify_time_step.sh` で再実行できます。

添付の summary_data.npz に、代表時刻の2D場、エネルギー曲線、スペクトルを保存しています。
全フレームは再実行により field.bin、section.bin に出力されます。

### 構成を調整する場合

現在の数値モデルは simulate.cpp の質量・バネ分布で定義しています。
左の高インピーダンス層は x=440、474、508 から各14格子、右は x=762、796 から各14格子です。
波源は configure.py、表示枠と解析領域は render.py・analyze.py に対応値があります。
層の位置やキャビティ幅を変えるときは、計算・表示・解析の3者を一致させてください。
