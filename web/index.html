このモデルについて

1,250 × 401 点のスカラー質点・ばね格子。元の C++ 版と同じ全計算領域を倍精度で更新します。表示のみ中央部分を切り出しています。5 枚の材料層で反射が生まれ、中央の波が重なります。

忠実な時間発展
減衰付き中心差分 leapfrog、Δt = 0.3。界面のばねは調和平均。端の吸収帯と固定端を含みます。

有限時間の励振
12 点の有限幅 Ricker パルス。T₀ = 80 は基準時間で、単一周波数の定常駆動ではありません。既定では全励振が約 4.55 T₀ で終了します。

読み取りの注意
色は変位で、エネルギーではありません。自動正規化は行いません。反射率、増幅、位相同期、非線形は設定していません。

ブラウザ版は 60 T₀ で停止します。詳細なエネルギー収支・高精度再現は README と native 版を参照してください。音響・電磁場をそのまま再現する汎用ソルバーではありません。
