パラメーター

物理パラメーターを変更した後は「適用」で静止状態から再計算します。

背景媒質での概算 λ ≈ √2 π σ（35.5–106.6 格子）。有限幅の Ricker 波は広帯域で、単一波長ではありません。スライダーとパルス幅は連動します。

速度と表示ゲインは物理モデルを変更しません。描画負荷に応じて実時間の速度は変わります。

配色（すぐ反映）

配色は場・凡例・中心断面に連動し、波や計算状態を変えません。見にくい配色になったら初期値に戻してください。

このモデルについて

1,250 × 401 点のスカラー質点・ばね格子。元の C++ 版と同じ全計算領域を倍精度で更新します。表示のみ中央部分を切り出しています。5 枚の材料層で反射が生まれ、中央の波が重なります。

忠実な時間発展
減衰付き中心差分 leapfrog、Δt = 0.3。界面のばねは調和平均。端の吸収帯と固定端を含みます。

有限時間の励振
自動デモは元の時刻で12波源を1回だけ発生。手動発生は同じ位置・符号・時間差を保ち、最初のパルスの裾を現在時刻から始めます。T₀ = 80 は基準時間です。

読み取りの注意
色は変位で、エネルギーではありません。自動正規化は行いません。波長は背景の c ≈ √(K/m) = 1 での概算です。材料層や格子分散で変わります。

ブラウザ版は 60 T₀ で停止します。その時刻までに1組を完了できない新規発生はできません。JSON は適用済み設定と最後の1組の記録のみで、場の保存・再開・設定の再読込には対応していません。詳細は README と native 版を参照してください。音響・電磁場をそのまま再現する汎用ソルバーではありません。
