# Wave Cavity Simulator

静止状態から生じる波、材料層での反射、空洞内の干渉を観察する、2D スカラー質点・ばねシミュレーションです。**TouchDesigner ファイルではありません。** インタラクティブなブラウザ版と、元の計算・解析・動画生成を行う C++ / Python 版を同梱しています。

## v1.1：発生・波長・配色コントロール

最新版をダウンロードして `web/index.html` を開くと、画面上部に **v1.1** と表示されます。

- **ボタンで波を出す**：「発生モード」を **手動** にして「適用してリセット」→「波を1回発生」→「開始」。発生ボタンは12波源を1組予約するだけで、時間を進めません。計算中に押す場合は、その時刻から発生します。
- **励振だけ止める**：「励振を止める」は追加の力だけを止めます。すでに伝播している波・時刻・開始／一時停止の状態は保持されます。
- **波長を変える**：「波長の目安」スライダー、または連動する「パルス幅」を変更して「適用してリセット」。背景媒質で約 **35.5–106.6 格子**、既定は約 **80 格子**です。厳密な単色波の波長ではありません。
- **見た目を変える**：「配色」で背景・文字・負／正の波色を変更できます。4種類のカラースケールとカスタム色に対応。凡例・中心断面も連動し、計算はリセットしません。見えづらくなったら白地の **「配色を初期値に戻す」** を押してください。

既定は元の **自動デモ** です。最初から1組が予約されているため、発生ボタンはその組が終了するか「励振を止める」まで無効です。手動モードでは、発生ボタンを押すまで完全な静止が続きます。

## まずブラウザで試す

1. GitHub の **Code → Download ZIP** でダウンロードし、ZIP を展開します。
2. 展開したフォルダーの **`web/index.html` をブラウザで開きます**。
3. **「開始 / Run」** を押します。最初は完全な静止状態で、既定設定では約 `0.67 T₀` から励振が始まります。

ビルド、npm、外部ライブラリ、ネット接続は不要です。最近の Chrome / Edge / Firefox / Safari を想定していますが、全ブラウザでの互換性確認は行っていません。計算負荷が高いためデスクトップを推奨します。

ローカルファイルの実行を制限する環境では、Python が入っていれば、このフォルダーで以下を実行して `http://localhost:8000/web/` を開けます。

```sh
python -m http.server 8000
```

### 操作

- **開始 / 一時停止**：時間発展を開始・停止します。
- **波を1回発生**：同じ12点から有限パルスを1組発生させます。停止中は予約のみで、時間発展は別の「開始」または「1 ステップ」で行います。1組の発生中は追加の予約を受け付けず、連打による蓄積はありません。終了・励振停止後はもう一度発生できます。
- **励振を止める**：現在の組の未発生分と残りの励振を取り消します。変位・直前の変位・時刻は変更しません。途中停止はパルスを打ち切るため、完全な Ricker パルスとはスペクトルが変わります。
- **1 ステップ**：停止し、`Δt = 0.3` だけ進めます。
- **静止に戻す**：現在適用済みの物理設定・発生モードで時刻ゼロに戻します。手動モードは波源なし、自動デモは元の組を再予約します。未適用の入力値はそのまま残ります。
- **発生モード・層の質量・ばね定数・励振振幅・波長／パルス幅**：入力後、「適用してリセット」で反映します。未適用の値は現在の波源や次の発生ボタンに影響しません。
- **材料層あり**：外すと一様媒質の比較計算になります。
- **物理設定を初期値に戻す**：既定の物理設定・自動デモに戻し、静止状態からやり直します。配色・表示ゲイン・計算速度は保持します。
- **計算速度**：1 描画フレームあたりの最大更新数です。応答性のため約 20 ms を超えるとそのフレームの更新を打ち切ります。実時間速度を保証するものではありません。
- **表示ゲイン**：色と中心断面の表示範囲だけを変更します。波そのものやエネルギーは変わりません。自動正規化はせず、範囲外の変位は飽和表示です。
- **配色**：背景色は画面・キャンバス・変位ゼロに共通です。波色は負→背景→正に補間し、表示ゲインの範囲外は端の色で飽和します。中心断面は正側／負側を同じ端の色で描きます。カラースケールの選択は背景色・文字色を変えません。
- **配色を初期値に戻す**：配色だけを戻します。背景と文字を同色にしてしまっても、このボタンは固定の高コントラストで表示します。物理設定・波・時刻・実行状態・表示ゲインは変更しません。
- **設定を JSON 保存**：適用済みの物理設定・発生モード・配色・表示ゲイン・現在時刻・最後の1組の波源と停止記録・組の累計数をローカルに保存します。未適用値、変位場、全発生履歴は含めません。状態の再開や設定の読み込み機能はありません。native 版の `parameters.json` とは形式が異なります。

### 波長・周波数と有限パルス

時間波形は `z = (t − center) / σ` に対する `(1 − z²) exp(−z² / 2)` です。理想的な Ricker 波の力のスペクトルのピークは `f_peak = 1 / (√2 π σ)`。長波長近似の背景速度 `c ≈ √(K/m) = 1` を使うと、`λ ≈ c / f_peak ≈ √2 π σ` となります。UI は `λ` を**格子間隔を単位とする背景での概算**、周波数を無次元の `f_peak × T₀` として表示します。Hz や実空間の長さではありません。`T₀ = 80` 自体は変更しません。

パルス幅は `σ = 8…24`、既定 `σ = 18` を保持しています。既定の正確な概算値は `λ ≈ 79.9719` で、表示の「80.0」から物理設定を丸め直しません。有限の打ち切り、空間包絡、減衰、格子分散がある広帯域の波なので、観察される変位の波長やスペクトルがこの値に厳密に一致するとは限りません。材料層では速度も異なります。

手動の各パルス中心時刻は `発生時刻 + 4σ + (元の中心時刻 − 元の最小中心時刻)` です。元の位置・符号・相対的な時刻差を保ち、最初のパルスの `−4σ` の裾が発生時刻から始まります。既定の1組の所要時間は約 `3.88 T₀`。1組を `60 T₀` までに完了できない場合、新規発生ボタンは無効になります。励振停止後も反射・透過・減衰による時間発展を続けられます。

## モデルと再現範囲

- `1250 × 401` 点、格子間隔 1、背景質量 1、背景ばね定数 1。
- 厚さ 14 点の材料層を `x = 440, 474, 508, 762, 796` に配置。既定の層質量 4、ばね定数 2。
- 各点に 1 個のスカラー変位。上下左右の最近接結合。界面のばね定数は調和平均。
- 減衰付き中心差分 leapfrog、既定 `Δt = 0.3`。外周固定端と周辺吸収帯。
- 初期変位・速度は厳密にゼロ。1組は12 個の局在 Ricker パルスです。時間包絡は `|z| > 4` で打ち切り、空間方向は正規化した 9 × 9 ガウス重み。
- `T₀ = 80` は基準時間です。励振は有限時間のパルスであり、単一周波数の連続駆動ではありません。既定の自動デモは元の時刻で1組だけ励振し、約 `4.55 T₀` で終了します。
- 反射係数、初期定在波、位相同期、利得、非線形を与えていません。

### ブラウザ版と native 版の違い

ブラウザ版も**全計算領域を縮小せず、Float64 で同じ差分式を更新**します。既定の 12 波源は元の生成結果と同一です。描画だけ `x=400…940, y=100…300` に切り出し、中心断面は `y=200` です。色は変位であり、エネルギー密度ではありません。

ブラウザ版の波源は seed `420731` で生成した元のリストを基にしています。native 版では seed を変更できます。ブラウザ版では `Δt`、格子、波源位置・相対時刻差を固定し、質量・ばね定数・振幅・幅・層の有無・自動／手動発生を調整できます。自動デモは元の絶対時刻、手動は上記のシフトした時刻を使います。60 `T₀` で停止します。native 版のようなエネルギー収支 CSV、時間刻み収束チェック、動画書き出しは行いません。長時間の再現・解析には native 版を使ってください。異なるパラメーターや手動発生の結果を元の既定設定の検証値と同一視しないでください。

これはスカラー格子の研究・可視化用モデルで、実際の音響・電磁気・弾性体をそのまま扱う汎用ソルバーではありません。吸収帯は完全整合層ではなく、残留反射や格子分散があり得ます。パラメーターの可変範囲は数値安定性を考慮して制限していますが、個々の設定の物理的妥当性は別途検証が必要です。

## テスト

リポジトリーのルートから実行します。

```sh
node tests/test_web.js
node tests/test_web_controls.js
python -m unittest discover -s tests -p 'test_native.py'
```

- `test_web.js`：厳密な初期静止、界面調和平均、独立に書いた差分式との比較、入力範囲、境界、一様媒質、波の発生、波長の式、手動波源の位置・時間差、停止直後の場保持と力の消去、その後の自由伝播、連打で増えない波源数、60 `T₀` の終端処理を検査。
- `test_web_controls.js`：小さな DOM / Canvas スタブを使って開始・停止・リセット・未適用値・設定適用・層なし・1 ステップ・初期値復帰、停止中の発生予約、発生停止、波長スライダー両端、無効入力、配色・凡例・中心断面の連動、表示変更時の状態保持、JSON 出力を検査。**実ブラウザの描画・互換性テストの代わりではありません。**
- 元 C++ の `field.bin` が手元にある場合、`node tests/test_web.js PATH/field.bin 225`（t=150）または末尾 `450`（t=300）で元出力との比較ができます。元の 120 frames/T₀ の時刻配列が前提です。生成済みバイナリーは同梱していません。
