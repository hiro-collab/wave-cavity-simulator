# Wave Cavity Simulator

**波を発生させ、材料層で反射した波が重なる様子をブラウザで観察する実験ツールです。**

波の発生・停止、波長の目安、材料の性質、配色を変えて比較できます。授業や説明の補助、波動の可視化を試す用途を想定しています。TouchDesigner は不要です。

> 2D のスカラー質点・ばねモデルです。音響・電磁場をそのまま再現する汎用ソルバーや、光の増幅を計算するレーザーシミュレーターではありません。

## 最短で試す

1. **[ZIP をダウンロード](https://github.com/hiro-collab/wave-cavity-simulator/archive/refs/heads/main.zip)** して展開します。
2. **`web/index.html` をブラウザで開きます。** ZIP の中ではなく、展開したファイルを開いてください。
3. **「開始 / Run」** を押します。初めは静止しています。画面の時刻が約 `0.67 T₀` になると波が出始めます。

インストール・ビルド・npm・外部ライブラリは不要です。計算負荷が高いため、まずはデスクトップの Chrome / Edge で試してください。取得後はネット接続なしで動きます。

ファイルを直接開けない環境では、Python があればリポジトリのルートで以下を実行し、`http://localhost:8000/web/` を開きます。

```sh
python -m http.server 8000
```

## 画面の見方

- **上の大きな表示**：波の変位を色で表示。縦の帯は材料層です。色はエネルギーの大小ではなく、変位の正負を示します。
- **下の折れ線**：中央の横一列（`y = 200`）を切り出した波形です。
- **パラメーター欄**：波や材料の条件を変更します。物理設定は「適用してリセット」で反映します。

## まず試したい3つの操作

### 1. 自分のタイミングで波を出す

「発生モード」を **手動** → **適用してリセット** → **波を1回発生** → **開始**。

発生ボタンは波源を予約するだけで、停止中の時間は進みません。「1回」は12点の波源を1組発生させる意味です。1組の途中では重ねて予約できません。

### 2. 反射の有無を比べる

既定設定の波を見た後、**「材料層あり」** を外して **「適用してリセット」→「開始」**。同じ波源を一様な媒質で動かした場合と比較できます。

### 3. 波の大きさと見え方を分けて変える

- **励振振幅**：波に加える力を変えます。「適用してリセット」が必要です。
- **表示ゲイン・配色**：表示だけを変更します。計算中の波は消えません。

## 主な操作

| 操作 | 何が変わるか |
|---|---|
| 開始 / 一時停止 | 計算を進める / 止める |
| 1 ステップ | 停止して、時間を `Δt = 0.3` だけ進める |
| 励振を止める | 追加の力を止める。既存の波は残る |
| 静止に戻す | 適用済みの条件で時刻ゼロへ戻る |
| 波長の目安 / パルス幅 | 波の時間幅を変える。変更後は適用が必要 |
| 層の質量 / ばね定数 | 材料層の性質を変える。変更後は適用が必要 |
| 計算速度 | 描画1回あたりの計算回数。物理モデルは変わらない |
| 設定を JSON 保存 | 適用済み設定を記録する。読み込み・途中再開機能ではない |

## 困ったとき

- **波が出ない**：自動デモは開始直後には静止しています。手動モードでは発生と開始の両方が必要です。
- **変更が反映されない**：物理設定は「適用してリセット」を押してください。
- **動きが重い**：「計算速度」を下げると操作の応答性を優先できます。進む速さはPC性能によって変わります。
- **色が見えなくなった**：「配色を初期値に戻す」を押してください。
- **最後で止まった**：ブラウザ版は `60 T₀` で停止します。再実行にはリセットが必要です。
